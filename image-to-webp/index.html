What is WebP?

WebP is an image format commonly used on websites because it supports efficient compression. It can handle photographic images as well as transparency, making it useful for many web assets.

WebP vs JPG and PNG

JPG is widely compatible and works well for photos. PNG supports lossless pixels and transparency. WebP can support both lossy and lossless-style workflows while often producing compact files for web use.
