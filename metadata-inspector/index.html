What is image metadata?

EXIF can include camera settings and sometimes location information. XMP stores descriptive information, while PNG chunks can carry metadata or technical image data.

Inspect without editing

Add JPEG, PNG or WebP images, then run the inspection. Review the reported markers for each file. Original files are not re-encoded, written back or modified by inspection.

About C2PA signals

Content Credentials can use signed provenance structures. Detecting a possible marker does not validate a signature, establish authorship or guarantee that metadata is absent.

Metadata Inspector FAQ

Can this tool prove an image is authentic?

No. This is a marker-oriented inspector, not an independent C2PA signature or trust-chain verifier.

Does examining a photo remove its GPS location?

No. Inspection is read-only. Use Metadata Cleaner if you need a new exported copy with common metadata removed.

What are PNG chunks?

PNG files contain chunks for image data and properties. Some chunks are essential to render an image, so not every PNG chunk is removable metadata.
