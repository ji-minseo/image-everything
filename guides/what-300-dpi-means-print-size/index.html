What 300 DPI Really Means: Pixels, DPI and Print Size

By Image Everything Editorial · Published October 20, 2026

Calculate printable image sizes from pixels and PPI, with accurate 300-pixel-per-inch examples, A4 calculations and realistic printing advice.

Open the image tools ↗

PPI is not the same measurement as printer DPI

People often say an image is 300 DPI, but for an image file the more precise term is 300 PPI: pixels per inch. DPI technically describes printed dots generated by a printer, and one image pixel may be reproduced with several ink dots. In practice, print shops may use the terms loosely. What you can calculate precisely is the relationship between pixel count, physical print dimensions and effective PPI.

How to calculate print dimensions

Divide the number of pixels along one side by the desired pixels per inch. A picture 2400 pixels wide at 300 PPI spans 8 inches. Multiply desired inches by 300 to calculate the pixels required for a 300-PPI output. Always calculate width and height separately and check whether the image's aspect ratio matches the paper or photo print.

Reference sizes at 300 PPI

The common 4-by-6-inch print calls for 1200 by 1800 pixels at 300 PPI. A 5-by-7-inch print requires 1500 by 2100; an 8-by-10 requires 2400 by 3000. A4 is 210 by 297 millimeters: converting each dimension to inches and multiplying by 300 gives about 2480 by 3508 pixels. Slight rounding differences are normal.

Changing a metadata number does not create resolution

A file that is 1200 by 1800 pixels has the same pixel count whether its resolution metadata says 72, 96 or 300 PPI. Changing that number without resampling changes the interpreted print size, not the sampled image detail. Enlarging the image by interpolation can add pixel values, but it does not recover details the camera never recorded.

What if the source has the wrong aspect ratio?

An image 2400 by 1600 pixels has a 3:2 ratio. An 8-by-10-inch print has a 4:5 ratio. Filling the paper without distortion requires cropping or adding margins. Decide on the composition before exporting so the subject is not cut off. Paper size and print quality are separate choices.

When 300 PPI is not necessary

High-quality art prints viewed at close range may benefit from a high effective pixel density. Posters viewed from farther away can look acceptable at lower PPI; a printer's recommendations and viewing distance matter. For normal screen use, CSS display dimensions and device scaling are more relevant than image resolution metadata. Check a proof print for work where color and sharpness matter.

Frequently asked questions

How many pixels do I need for an 8 by 10 print?

At 300 PPI, 2400 by 3000 pixels, assuming no additional crop.

Does setting 300 DPI improve a blurry image?

No. Changing a metadata value does not create captured detail.

Is A4 exactly 2480 by 3508 pixels?

Those are the approximately rounded dimensions at 300 PPI from A4 millimeters.
