# Image Everything — 2026-10-31 리브랜딩 및 기존 도메인 운영 결정

## 디자인 가드레일
- **일반적인 현대적 SaaS / 웹 유틸리티 스타일**, 과장된 잡지(에디토리얼) 스타일 금지.
- 흰색 전체 배경, 산세리프 Inter/시스템 폰트. 배경을 검은색/짙은색으로 깔지 않는다.
- 기본 글씨는 충분히 읽기 쉽게. 아이브로우·보조 라벨 **12px 미만 금지**. 툴 설명은 가급적 14px 이상.
- 불필요한 실선/구분선, 카드 보더 남발하지 말 것. 여백과 텍스트 크기/굵기 우선. 보더는 구획을 구별할 때만 가볍게.
- 블랙은 주요 CTA·본문 텍스트, 라벤더는 작은 강조/상태 표현에만 절제해서 사용.
- 화면과 모바일 프리뷰를 직접 확인하기 전까지 '디자인 완성'이라고 하지 않는다.
- 이미지/PDF/영상/메타데이터 **기존 17개 도구의 독립 URL은 계속 유지**. 도구 통합·삭제 금지.
- 한국어 페이지 리브랜딩은 프리뷰 및 기능 검증과 함께 별도 진행.

## 자 도구는 미래 후보
- 화면 자 도구와 `screen-ruler-accuracy-calibration` 가이드는 **이번 릴리스에만 포함하지 않는다**.
- 향후 제품 범위를 확장할 경우, 별도 `/actual-size-ruler/` URL과 원본 가이드의 합류를 다시 평가할 수 있다.
- 현재 Every Tiny Tool의 화면 자 기능/가이드를 삭제하거나 영구 제외로 취급하지 않는다.

## 도메인/구 사이트: 지금 해지하거나 지우지 않음
1. `everytinytool.com`: 기존 콘텐츠/도구의 출처이자 `image.everytinytool.com` 등 서브도메인의 상위 도메인. **지금 도메인 등록을 해지하지 않는다**. 타 프로젝트/서브도메인의 영향 검증 필수.
2. `image.everytinytool.com`: 새 독립 도메인 출시 전까지 유지. 이후 **새 사이트의 해당 URL로 301/308 리디렉션**; DNS 제거가 아니라 응답 가능한 상태로 둔다.
3. `everytinytool.com` 메인의 중복 이미지·PDF·영상·메타데이터 기능 및 가이드는 **새 도메인 라이브·작동 검증 완료 후** 정리. 옮긴 URL은 1:1 대응표에 따라 리디렉션.
4. 목록 비교/화면 자 기능 및 가이드, Random / Calculate 등 나머지 사이트는 **이번 이전 대상이 아니다**. 무관한 서비스나 결제 설정을 건드리지 않는다.
5. Google의 권장 기준에 따라 이전 URL의 영구 리디렉션을 **적어도 1년**, 가능하면 더 길게 유지한다. 새 도메인 구입/Cloudflare 전환만으로 색인을 보장하지 않는다.
6. 원 도메인 및 DNS는 기존 다른 서브도메인 운영에도 필요하므로 일괄 해지·삭제 금지. 도메인 갱신/만료 날짜를 별도로 점검한다.

## 실행 시점
**지금**: 디자인/가이드/기능 QA, 프리뷰, 1:1 URL 매핑, 신규 도메인 후보 검토. 
**출시 직전**: 신규 도메인 소유권 확보·DNS 연결, 구·신 사이트 HTML/헤더/canonical/robots/sitemap 확인, 301 준비.
**출시 후**: 기존 중복 콘텐츠 제거, 실제 301 활성화, Search Console 변경/사이트맵 제출, 색인·트래픽 점검.
**나중**: 기존 플랫폼 운영 중단은 사용자가 실제 링크와 DNS가 정상 작동하는지 확인한 뒤 결정. 최상위 everytinytool.com 도메인 해지는 권장하지 않음.
