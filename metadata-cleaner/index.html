How to clean image metadata

Choose one or more JPEG, PNG or WebP files. Leave camera EXIF retention off for a general re-encoded copy, then download completed files individually or in a ZIP.

Keep selected camera settings

For JPEG files, you can try retaining a limited set such as camera maker, model and exposure settings. The option excludes GPS data; not all source tags are supported.

What changes?

Canvas-based re-encoding may change compression, image color, orientation or quality. Re-encoding can invalidate C2PA signed provenance. Check the image visually and inspect the exported file.

Metadata Cleaner FAQ

Can all C2PA records and hidden metadata be guaranteed removed?

No. This tool targets common image metadata in supported browser-decoded formats; it is not a forensic sanitization guarantee.

Does camera-only EXIF work for PNG and WebP?

The optional camera-only EXIF reinsertion is intended for JPEG files only. Other files are exported without that selected EXIF set.

Will my original image be changed?

No. The cleaned result is a separate downloaded file. Keep your original if you need to preserve its exact bytes or signed provenance.
