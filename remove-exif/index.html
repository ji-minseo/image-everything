EXIF & GPS Cleaner

Remove EXIF metadata—including embedded GPS data—from supported image files while leaving other metadata containers in place where possible.

🧹

Drop images here

JPEG, PNG and WebP supported

This tool targets EXIF metadata only. XMP and content-credential/provenance containers are not deliberately stripped. Any file modification can still affect the validity of signed provenance credentials. Removing EXIF may also remove camera orientation data.

Future ad space

Privacy-focused cleanup

EXIF can include camera details, timestamps and GPS coordinates. This tool removes the EXIF container from supported files.

No intentional recompression

JPEG, PNG and WebP are rewritten at the container level so the encoded image data is not intentionally recompressed.

Provenance stays separate

The cleaner does not deliberately strip XMP or provenance containers. Use Metadata Checker to inspect those signals before editing.
