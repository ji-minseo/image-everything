자주 묻는 질문

이미지 에브리씽 자주 묻는 질문

이미지가 서버에 업로드되나요?

지원되는 이미지 도구는 브라우저에서 처리하므로 일반적인 작업 시 이미지 파일 자체를 서버에 보낼 필요가 없습니다.

회원가입이 필요한가요?

아니요. 회원가입이나 로그인 없이 사용할 수 있습니다.

어떤 파일 형식을 지원하나요?

도구마다 지원 형식이 다르며 JPG·JPEG·PNG·WebP 등을 주로 지원합니다.

여러 이미지도 한 번에 처리할 수 있나요?

네. 일괄 처리 지원 도구에서는 여러 파일을 변환하거나 압축하고 ZIP으로 다운로드할 수 있습니다.
