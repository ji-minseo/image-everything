PNG compression uses local color quantization in your browser. Transparency is preserved. If a compressed result would be larger than the original, the original file is kept instead.

Real PNG size reduction

The compressor reduces the number of colors used in the PNG, a technique called color quantization. This can make PNG files much smaller while keeping transparency.

Choose the tradeoff

Use more colors for finer gradients and fewer colors for smaller files. A target size can automatically try progressively smaller palettes.
