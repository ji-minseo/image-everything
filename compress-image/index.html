How to compress an image

Choose one or more images, pick a quality level and press Compress images. Download files individually or grab the whole batch as one ZIP.

No server upload

The current compressor works with browser canvas APIs. Your image pixels stay on your device while the tool runs.

Target a file size

Enter a target such as 200 KB to let the tool search for a smaller result automatically. Leave it blank to use the quality control only.
