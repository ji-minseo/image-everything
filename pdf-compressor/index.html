Why the size target isn't guaranteed

PDFs can contain photos, scans, fonts, vector graphics and embedded files. Some compress extremely well, while others are already optimized. Aggressive shrinking can make small text blurry. Always review the downloaded PDF before sharing or submitting it.

PDF compression FAQ

Can I compress a PDF to under 10 MB?

Choose “Under 10 MB” and the tool will try several increasingly aggressive settings. If your PDF is already below 10 MB it stays unchanged. Some files cannot reach the limit without unacceptable loss, so the tool reports when the target was missed instead of claiming success.

Does “40% smaller” guarantee a 40% reduction?

No. It is your goal. The actual compression ratio depends on the images and data already in the PDF, and the resulting file size is displayed when processing finishes.

Will I still be able to select or search PDF text?

If the file needs recompression, the tool redraws each page as an image and saves a new PDF. This usually removes selectable/searchable text, editable form fields, bookmarks and clickable links. Use a professional document-preserving compressor if you need those features.

Are my PDFs uploaded to a server?

No. PDF pages are read and processed by JavaScript locally in your browser. The required processing libraries are downloaded by the browser, but the document file itself is not sent to our servers for compression.

Can I compress a password-protected PDF?

No. Unlock a password-protected PDF in a trusted application first. This tool also has a 180 MB upload-size processing limit and a 120-page limit to reduce browser memory problems.

Why is my compressed PDF blurry?

Image-based compression reduces image resolution and JPEG quality to save space. If readability matters more than file size, choose a less ambitious target. This tool is especially suitable for image-heavy scans and files where copyable text is not required.
